Como será aberto no notebook

  1. Instalar o pacote local do painel e os componentes USB necessários.
  2. Conectar o celular por cabo USB de dados e autorizar o computador no Android.
  3. Iniciar o serviço local do painel.
  4. O serviço abrirá esta página no navegador padrão e acompanhará a sincronização.

O endereço final será local, por exemplo http://127.0.0.1:8765. Não é um endereço ativo nesta versão estática.
